## 🧠 Problem-Solving Approach

For coding problems, I try to follow this process:

```text
Understand the Problem
        ↓
Identify Constraints
        ↓
Think of Brute Force
        ↓
Find an Optimized Approach
        ↓
Implement
        ↓
Test Edge Cases
        ↓
Analyze Time Complexity
        ↓
Analyze Space Complexity
```

The objective is not only to solve a problem, but to understand **why the solution works and how it can be improved**.

## 📝 Problem Format

Each coding problem is documented with:

```text
Problem
Approach
Solution
Time Complexity
Space Complexity
Edge Cases
```

Example:

```text
Problem:
Find the two numbers in an array that add up to a target.

Approach:
Use a hash map to store previously seen values.

Time Complexity:
O(n)

Space Complexity:
O(n)
```

This helps me practice explaining solutions during technical interviews, not just writing code.
